Cada clic agrega o quita un asiento de la lista y recalcula el total.

function seleccionarAsiento(event) {
  const asiento = event.target;
  const fila = asiento.dataset.fila;
  const asientoNum = asiento.dataset.asiento;
  const precio = asiento.dataset.precio;

  // Verificar si el asiento ya está seleccionado
  const indiceSeleccionado = asientosSeleccionados.findIndex(
    s => s.fila === fila && s.asiento === asientoNum
  );

  if (indiceSeleccionado !== -1) {
    if (confirm('¿Desea deseleccionar el asiento?')) {
      asientosSeleccionados.splice(indiceSeleccionado, 1);
      eliminarFilaResumen(fila, asientoNum);
      calcularTotal();
    }
  } else {
    asientosSeleccionados.push({ fila, asiento: asientoNum, precio });
    agregarFilaResumen(fila, asientoNum, precio);
    calcularTotal();
  }
}

Base de datos de tienda virtual

Base de datos relacional normalizada (3FN) para una tienda virtual de tecnología. Desarrollé gran parte del proyecto en equipo: el modelo de tablas y los procedimientos almacenados con transacciones y savepoints.

SQL Server T-SQL

Procedimiento con transacción y savepoint: si algo falla, deshace el cambio y devuelve un código de error.

CREATE PROCEDURE GestionTienda.InsertarVenta
    @ClienteID         INT,
    @Total             DECIMAL(12,2) = NULL,
    @CodigoRespuesta   INT           OUTPUT,
    @DescripcionSalida NVARCHAR(200) OUTPUT,
    @Mensaje           NVARCHAR(100) OUTPUT
AS
BEGIN
    SET NOCOUNT ON;
    BEGIN TRY
        BEGIN TRANSACTION;
        SAVE TRANSACTION sp_InsertarVenta;

        INSERT INTO GestionTienda.Ventas (ClienteID, Total)
        VALUES (@ClienteID, @Total);

        COMMIT TRANSACTION;
        SET @CodigoRespuesta   = 200;
        SET @DescripcionSalida = 'Inserción exitosa';
        SET @Mensaje           = 'Venta registrada correctamente';
    END TRY
    BEGIN CATCH
        ROLLBACK TRANSACTION sp_InsertarVenta;
        SET @CodigoRespuesta   = 500;
        SET @DescripcionSalida = ERROR_MESSAGE();
        SET @Mensaje           = 'Error al insertar venta';
    END CATCH
END

Calculadora de figuras geométricas

Aplicación en Java con programación orientada a objetos que calcula áreas de figuras geométricas. Desarrollé la parte del cálculo de las áreas.

Java POO

Calcula el área de un triángulo a partir de sus tres lados con la fórmula de Herón.

public class trianguloHeron extends areaFigurasPlanas {

    private double ladoA;
    private double ladoB;
    private double ladoC;

    public trianguloHeron(double ladoA, double ladoB, double ladoC) {
        super("Triangulo (Heron)");
        this.ladoA = ladoA;
        this.ladoB = ladoB;
        this.ladoC = ladoC;
    }

    public double calcularArea() {
        double semiperimetro = (ladoA + ladoB + ladoC) / 2;
        return Math.sqrt(semiperimetro * (semiperimetro - ladoA)
                * (semiperimetro - ladoB) * (semiperimetro - ladoC));
    }
}
